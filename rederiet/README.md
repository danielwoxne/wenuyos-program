# Rederiet 0.1.0

Ett eget, resurssnålt rederispel för WenuyOS, inspirerat av klassiska sjöfarts- och handelsspel. Ingen kod eller grafik från Ports of Call används.

**Status:** Pågående utkast. Den lokalt framtagna prototypen omfattar GTK4-gränssnitt, fraktuppdrag, resor, ekonomi, bränsle, reparationer och sparning. Fem spelmotorprov körda lokalt, grafiskt prov på WenuyOS återstår. Källfiler behöver föras över innan PR kan granskas.

Inga nätverksanrop, inga hemligheter. Programmet ska fungera på 2 GB RAM och mjukvarurendering.
