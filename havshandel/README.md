# Havshandel – Rederiet

Ett litet fristående rederispel för WenuyOS (Debian 13, GTK4). Inspirerat av den klassiska genren, med egna spelregler och egen grafisk presentation.

**Status:** prototyp under utveckling på denna gren. Inget släpp.

Målet är att hantera fartyg, hamnar och fraktavtal utan nätverk, på datorer med 2 GB RAM och mjukvarurendering.
