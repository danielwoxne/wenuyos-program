# Namnkontroll – arbetsnamn

Utvecklingsnamnet Aetheria är inte verifierat som fritt varumärke.
Under november 2026 hittades flera andra spel med Aetheria i titeln,
inklusive en publikation på Steam från 28 april 2026.
Källor: https://store.steampowered.com/app/3764710/Aetheria/
         https://steamdb.info/app/5129470/

Undvik därför att påstå ensamrätt, registrera domän, marknadsföra offentligt
eller publicera bred release innan en riktig EUIPO/PRV-inriktad genomgång.
Interna testbyggen kan kallas Aetheria som tillfälligt projektnamn.
